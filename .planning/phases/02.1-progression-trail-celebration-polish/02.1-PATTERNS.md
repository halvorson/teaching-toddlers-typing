**Pattern to copy:** the single-chokepoint principle itself — every caller (`celebrate()` at

```typescript
// NEW — pure, no caching, no resize listener (UI-SPEC Celebration Scaling Contract)
function viewportScaleFactor(): number {
  const widthRatio = window.innerWidth / 1280
  const heightRatio = window.innerHeight / 800
  const factor = Math.sqrt(widthRatio * heightRatio)
  return Math.min(2.5, Math.max(0.8, factor))
}

confetti({ ...opts, startVelocity: opts.startVelocity * viewportScaleFactor(), colors: CONFETTI_COLORS })
```

UI-SPEC assumption 8.

**Error handling pattern:** already-established try/catch-and-swallow (line 34-39) — no change
needed, `viewportScaleFactor()` is a pure synchronous function with no failure mode to guard.

**Error-handling pattern to copy** (from `src/clipboard.ts:34-43`):

```typescript
try {

    await navigator.clipboard.writeText(url)
```

This "expected-failure, fall through to next tier, no error UI" shape is exactly what
`readSettings()`/`writeSettings()` need for unavailable/quota/private-browsing localStorage.

**Concrete shape to build** (per `02.1-RESEARCH.md`'s Code Examples and `02.1-UI-SPEC.md`'s
Persistence section — illustrative, not yet in the codebase):
```typescript
const STORAGE_KEY = 'keyboard-quest-settings' // exact string is planner's/executor's choice

interface SettingsV1 {
  version: 1
  resetTrailOnMistake: boolean
}

const DEFAULT_SETTINGS: SettingsV1 = { version: 1, resetTrailOnMistake: false }

export function readSettings(): SettingsV1 {
  try {
    const raw = localStorage.getItem(STORAGE_KEY)
    if (!raw) return DEFAULT_SETTINGS
    const parsed = JSON.parse(raw)
    if (parsed?.version === 1 && typeof parsed.resetTrailOnMistake === 'boolean') return parsed
    return DEFAULT_SETTINGS
  } catch {
    return DEFAULT_SETTINGS // silent in-memory fallback — matches celebrate.ts precedent
  }
}

export function writeSettings(settings: SettingsV1): void {
  try {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(settings))
  } catch {
    // Silent — decorative/utility failures fail silently, matching celebrate.ts
  }
}
```

**Validation pattern:** shape-check every field (`typeof parsed.resetTrailOnMistake === 'boolean'`,
`parsed.version === 1`) before trusting a parsed localStorage value — never trust `JSON.parse`'s
output structurally, since a hand-edited DevTools value must degrade to the default, not throw
uncaught (ASVS V5, per RESEARCH's Security Domain section).
