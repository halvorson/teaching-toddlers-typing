## Tests

### 1. Star trail accumulation, layering, and mode-entry reset
expected: Run `npm run dev`, choose Letters, press the matching physical key 10-15 times in a row, then Escape and re-enter Letters. Each correct press adds one small purple glowing dot at a new random spot; dots accumulate; target letter always renders above any dot; no dots on the home menu; re-entering Letters starts empty.
result: pass

### 2. Star pop-in animation vs. reduce-motion
expected: With OS Reduce Motion OFF, each star fades/scales in over ~300ms then stays at full brightness. With Reduce Motion ON, each star appears instantly at full size with no entrance animation.
result: pass

### 3. Viewport-scaled confetti burst
expected: At ~640x480 the burst looks essentially unchanged from Phase 1. On a large/fullscreen display the same burst throws particles noticeably further and covers much more of the screen while settling in about the same time (bigger, not faster). Z-completion celebration remains clearly the largest burst at both sizes.
result: pass
reason: "Tested via laptop monitor (small) vs. desktop monitor (large) instead of window-resize-vs-fullscreen, since exiting fullscreen mid-mode returns to the menu (expected FULL-01 behavior, not a bug). Scaling difference confirmed across the two screen sizes."

### 4. Settings screen reachability, keyboard nav, layering, and persistence
expected: Settings opens as a centred dark card over the drifting background (never fullscreen, never blank, no star dots behind it), reachable by mouse and keyboard (Tab/arrow + Space), toggle track turns purple with thumb sliding right when on, Escape and '← Back' both return to menu, toggle position survives a hard reload, URL reads `?screen=settings` while open.
result: pass

### 5. Trail-reset toggle gameplay effect
expected: With toggle OFF (default), a wrong key produces only the usual neutral flicker and all stars stay put. With toggle ON, a wrong key produces the flicker AND all stars disappear at once, refilling from the next correct match. No error text/sound/punitive cue either way.
result: pass
