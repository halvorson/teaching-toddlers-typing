## Sampling Rate

- **After every task commit:** Run `npm run build` (must exit 0) + manual `npm run dev` smoke check
  of the change just made.
- **After every plan wave:** Run `npm run build && npm run preview`, manual walkthrough of the
  requirements landed in that wave, on at least two browser engines.
- **Before `/gsd:verify-work`:** Full manual walkthrough of all 4 requirements (TRAIL-01, TRAIL-02,
  CELEB-01, CELEB-02) on the live GitHub Pages URL, including the extended-session smoke check.
- **Max feedback latency:** ~1 min (build time).

## Manual-Only Verifications

| Behavior | Requirement | Why Manual | Test Instructions |
|----------|-------------|------------|--------------------|
| Star trail visual density/scatter reads as ambient, not patterned | TRAIL-01 | Subjective visual judgment — not assertable by static analysis | Play ~10+ correct matches in one mode, confirm stars appear scattered (not gridded/linear) and never obscure the target letter |
| Toggle-gated trail reset (ON = full wipe, OFF = no effect) | TRAIL-02 | Live interaction + visual confirmation of a full DOM wipe vs. no-op | With toggle ON, press a wrong key mid-trail and confirm all stars vanish; with toggle OFF (default), confirm they persist through a wrong key |
| Confetti burst reads visibly larger/further on a high-resolution monitor | CELEB-01, CELEB-02 | Visual size/scale comparison across real displays — not assertable by static analysis | Compare a correct-match burst at a small window (~640x480) vs. a large/fullscreen high-DPI display; confirm noticeably larger travel radius at the same perceived speed |
| Extended-session trail accumulation (hundreds of stars) doesn't visibly degrade feel/performance | TRAIL-01 | No automated perf harness exists (per CLAUDE.md); no cap/cycling logic is built by design | Play an extended session (50+ correct matches) in one mode without switching, confirm the app still feels responsive |
| `prefers-reduced-motion` suppresses star pop-in and confetti as expected | TRAIL-01, CELEB-01, CELEB-02 | OS-level motion setting only testable live | Enable OS reduce-motion, confirm stars appear instantly (no pop-in) and confetti still fires but the pre-existing reduced-motion confetti suppression (celebrate.ts) is unaffected by the new scaling |
