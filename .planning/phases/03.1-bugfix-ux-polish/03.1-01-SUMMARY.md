# Phase 03.1 Plan 01: Home Menu Left-Alignment & color-mix() Cascade Fallbacks Summary

**Left-docked home menu with an on-screen "Teaching Toddlers Typing" title via a single `.home-menu` wrapper, plus defensive `color-mix()` cascade-fallback declarations restoring the drifting parallax background and star trail to a plain-color rendering path.**

## Performance

- **Duration:** 6 min
- **Started:** 2026-08-14T19:39:00Z (approx, per STATE.md session start)
- **Completed:** 2026-08-14T19:45:00Z (approx, per last commit timestamp)
- **Tasks:** 3
- **Files modified:** 2 (src/menu.ts, src/style.css)

## Accomplishments
- `mountMenu()` now builds a `div.home-menu` wrapper (title + nav) instead of appending `nav.menu` directly to the container, giving the title and list one shared left-margin source
- `.home-menu` uses `margin-right: auto` as a scoped left-alignment opt-out, leaving `#app`'s `justify-content: center` untouched so Settings and Statistics panels stay centered
- `body::before`/`body::after` (drifting parallax background) and `.star-trail__star` (ambient trail) each gained a plain `var(--color-surface)`/`var(--color-accent)` fallback declaration immediately preceding their existing `color-mix()` declaration — a browser that fails to parse `color-mix()` now falls back to a solid-tinted rendering instead of an invisible one

## Files Created/Modified
- `src/menu.ts` - `mountMenu()` creates `div.home-menu` wrapping `h1.home-menu__title` ("Teaching Toddlers Typing") + the existing `nav.menu`; `container.appendChild(wrapper)` replaces the prior `container.appendChild(nav)`
- `src/style.css` - New `.home-menu`/`.home-menu__title` rules after `#app`; plain-color fallback `background`/`box-shadow` declarations added ahead of every existing `color-mix()` use in `body::before`, `body::after`, and `.star-trail__star`

## Decisions Made
- Single `.home-menu` wrapper (not independently-styled title + nav) so title and list can never drift apart on their left margin — matches the plan's explicit "single wrapper" design intent
- Cascade-fallback pairing (plain-color declaration immediately before `color-mix()`) chosen over `@supports (color: color-mix(...))` queries — zero extra rule blocks, and a no-op when `color-mix()` IS supported since the cascade simply keeps the later, more specific declaration
