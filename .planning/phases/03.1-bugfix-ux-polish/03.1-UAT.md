expected: The background is visibly rendering, with no hard seams, at any screen size.

### 4. AUDIO-03 — correct TTS pronunciation, no "Capital" prefix, no wrong-letter mispronunciation
expected: Every letter's spoken name is correct and unambiguous on the user's actual device/voice.
result: **PASS** (after 1 fix round). Original "Capital E"-style prefix bug confirmed fixed. A
  follow-up listening pass found 2 of 26 letters mispronounced on the user's Mac + Chrome/Safari
  voice: A sounded like "I", G sounded like "C". Traced via claude-in-chrome to confirm this was a

  time). Fixed: G "Jee"→"Gee" (real dictionary word, not an invented spelling); A "Ay"→"Ey" (leans
  on the more reliable "-ey" digraph pattern vs. "ay"'s ambiguity with the interjection reading).
  Commit `68d9139`. User did not re-flag A/G after this fix — confirmed passing.

  code reviewer can catch; only a human looking at / listening to the real thing can.
