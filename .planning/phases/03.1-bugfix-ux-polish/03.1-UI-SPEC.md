# Phase 3.1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase shape:** Four of five requirements (AUDIO-03, MENU-04, TRAIL-03, DOCS-01) are
root-cause bugfixes restoring already-designed, already-verified behavior from Phase 2 /
2.1 / 3 — no new visual decisions apply to those. This contract's only **net-new** visual
surface is MENU-05: a left-aligned home menu with an on-screen title. Sections below are
scoped accordingly — bugfix items get an explicit "target state" (so the checker/executor
know exactly what "fixed" looks like) rather than new tokens.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0A0E1B` (`--color-bg`) | Page background, gameplay field |
| Secondary (30%) | `#1E2340` (`--color-surface`) | Settings panel, share-URL input, drifting-background gradient tint, incorrect-flash tint |
| Accent (10%) | `#8B7FFF` (`--color-accent`) | Reserved for interaction/feedback states only — see list below |
| Destructive | `#C4607A` (`--color-destructive`) | Reserved, unused in this phase (Quit is not redesigned until Phase 4.1/MENU-06) |
| Foreground | `#F3F1FA` (`--color-fg`) | Body/heading text, resting menu-item text, **new: title text (MENU-05)** |

Accent reserved for (unchanged this phase — no new accent usage added):
- Focused menu row's text color + underline (`.menu-item.focused`)
- Toggle-switch active track + focus-visible outline (Settings)
- Correct-match pulse glow (`#target.correct-pulse` drop-shadow)
- Star-trail star glow (`.star-trail__star` radial gradient/box-shadow)

**Design decision — the new title stays `--color-fg`, not accent.** Accent is scarce by design (10% budget, reserved for *interactive/feedback* states only); the title is static content, not an interactive element, so coloring it accent would both blow the reserved-for list and compete visually with the focused-row indicator directly below it. This keeps the accent's meaning ("this is selected / this just happened") unambiguous.

## Layout Contract — Home Menu Left-Alignment (MENU-05)

Concrete values for the one net-new visual element, so plan/execute have zero ambiguity:

- **Left margin**: `max(64px, env(safe-area-inset-left))` — reuses the exact `max(fixed, env(safe-area-inset-*))` pattern already established on `#app`'s padding (`src/style.css` line 114), just with the 3xl (64px) token instead of md (16px). This reads as a deliberate "left-docked column," per Slay the Spire, without ever touching the literal viewport edge.
- **Vertical centering**: preserved unchanged (`#app`'s `align-items: center` stays as-is) — only the horizontal axis changes, per CONTEXT.md's explicit scoping.
- **Scope**: home menu only. Settings and Stats keep their existing centered windowed-panel treatment (`.settings-panel`, `max-width: 480px`, centered) — do not apply this left-margin rule to `body[data-chrome="menu"]` broadly, since that attribute value also covers Settings. Scope the CSS to the home-menu markup specifically (e.g. a wrapper class distinct from `.settings-panel`), not to the shared `data-chrome="menu"` attribute.
- **Composition**: title sits directly above the menu list, sharing the identical left margin — implement as one wrapper containing the title element followed by the existing `<nav class="menu">`, so both inherit one left-margin declaration instead of two that could drift apart.
- **Title-to-list gap**: 32px (xl token) between the bottom of the title and the top of the first menu row.
- **Title wrapping**: normal inline wrap (no `white-space: nowrap`, no truncation/ellipsis) — the string is short and fixed, but must not be forced onto one line if a narrow viewport can't fit it at the declared `clamp(32px, 6vh, 48px)` size.
- **Title max-width**: constrain to 480px (matches `.settings-panel`'s existing max-width, keeping the two windowed/non-windowed surfaces visually consistent in scale) so the title doesn't stretch full-bleed on wide desktop viewports.
- **No new assets**: pure CSS (existing custom properties only) — no image, no custom font, no icon added for the title.
