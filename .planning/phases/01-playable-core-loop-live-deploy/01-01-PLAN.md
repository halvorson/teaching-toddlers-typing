<objective>
Stand up the walking skeleton for Keyboard Quest: a real Vite + TypeScript project in this
repository, themed with the locked pearlescent palette, rendering one large centered letter,
built with the correct GitHub Pages base path, and published live at
https://halvorson.github.io/teaching-toddlers-typing/ by the official 3-action Pages workflow.

Purpose: DEPLOY-02 exists precisely because a `base`-path misconfiguration produces a silent
blank page that is easy to misdiagnose once real game logic is present. Proving the whole
pipeline — scaffold → build → Actions → live URL — on a single letter isolates that failure
mode from every gameplay bug that follows. This is the phase's tracer slice.

Output: A committed, deployed static site plus the architectural decisions recorded in
`01-SKELETON.md` that Plan 02 and Phases 2-4 build on without alteration.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → local build | Third-party package code executes during install and is bundled into the published artifact |
| GitHub Actions runner → GitHub Pages | An automated token publishes content to a public origin |
| Public internet → published repository | Everything committed becomes permanently world-readable |
| Browser DOM ← app source | The only rendering path that could interpret a string as markup |
